> **עדכון אחרון:** 2026-06-28 — v3.8.40

67router חושף שלושה ממשקים שונים הקשורים לסוכנים. במבט ראשון הם נראים דומים, אך הם פותרים בעיות שונות. השתמשו בדף זה כדי לבחור את הממשק המתאים.

## בקצרה

| ממשק                     | מתאים במיוחד עבור                                                                                                       | תעבורה                                | תקן                  |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------- | -------------------- |
| **A2A — סוכן-לסוכן**     | שיתוף פעולה בין סוכנים עם סוכנים עמיתים שתומכים בפרוטוקול A2A                                                           | JSON-RPC 2.0 מעל HTTP                 | A2A v0.3 (מפרט פתוח) |
| **ACP — מרשם סוכני CLI** | זיהוי / רישום / הפעלה של סוכני תכנות מסוג CLI המותקנים במחשב המשתמש (Cursor, Cline, Codex CLI, Claude Code, Aider וכו׳) | HTTP REST                             | ייחודי ל-67router    |
| **סוכני ענן**            | שליחת משימות תכנות ממושכות לשירותי ענן חיצוניים (Codex Cloud, Devin, Jules, Cursor Cloud)                               | HTTP REST + משימות מגובות במסד נתונים | ייחודי ל-67router    |

שלושת הממשקים בלתי תלויים זה בזה — ניתן לבחור כל תת-קבוצה שלהם.

## עץ החלטה

## 2. ACP — מרשם סוכני CLI

**נקודת הקצה של 67router:** `GET /api/acp/agents`
**מקור:** `src/lib/acp/{index,manager,registry}.ts`

### מה זה

ACP הוא **מלאי סוכני ה-CLI המקומיים** של 67router. הוא מזהה אילו כלי CLI לתכנות מותקנים במארח (Cursor, Cline, Claude Code, Codex CLI, Continue וכו׳), מאתר את הגרסאות שלהם ומציג אותם בלוח הבקרה, כדי שהמשתמש יוכל להגדיר כל CLI כך שיפנה אל 67router.

ממשק ה-HTTP הוא מלאי פנימי שמפעיל את ממשק המשתמש "CLI Tools" ואת
מעקב טביעות האצבע של כלי CLI (ראו [CLI-TOOLS.md](../reference/CLI-TOOLS.md)). בנפרד,
מנהל התהליכים הפנימי תומך באופן מובנה ב-Agent Client Protocol עבור מפעיל Gemini
הרשום ובמתאמי stdio מדור קודם עבור חוזים אחרים.
ראו [המרשם והמפעילים של ACP](./ACP.md) למידע על המצבים והמגבלות הנפרדים האלה.

### מה הוא עושה

- בודק אם קובצי הרצה של כלי CLI מותקנים במארח (באמצעות `which` / `where` בהתאם למערכת ההפעלה)
- קורא את הגרסה של כל CLI (באמצעות קריאה ל-`<bin> --version`)
- מאפשר, באופן אופציונלי, סוכנים מותאמים אישית שהוגדרו בידי המשתמש (נתיב לקובץ הרצה + בדיקת גרסה + ארגומנטים להפעלה)
- שומר סוכנים מותאמים אישית בהגדרות
- מחזיר את הרשימה המאוחדת ללוח הבקרה

### API מסוג REST

| נקודת קצה         | שיטה | תיאור                                                         | אימות    |
| ----------------- | ---- | ------------------------------------------------------------- | -------- |
| `/api/acp/agents` | GET  | הצגת סוכנים שזוהו + סוכנים מותאמים אישית (מספר מותקנים/כולל)  | מפתח API |
| `/api/acp/agents` | POST | הוספה/עדכון/הסרה של סוכן מותאם אישית (מבחין פעולה בגוף הבקשה) | מפתח API |

מבנה גוף הבקשה עבור POST (`customAgentBodySchema` בתוך `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### תרחישי שימוש

- הדף "CLI Tools" בלוח הבקרה מציג אילו כלים מותקנים ומסייע להגדיר כל אחד מהם כך שיפנה אל 67router
- סוכנים מותאמים אישית מאפשרים למשתמשים מתקדמים לרשום כלי CLI פנימיים/קנייניים ש-67router אינו מכיר כברירת מחדל
- תוצאת הזיהוי משמשת את מטריצת טביעות האצבע `cli-tools`

### מתי אין להשתמש ב-ACP

- מרשם ה-HTTP אינו מקבל משימות ואינו חושף הפעלת תהליכים. המנהל הפנימי
  יכול להפעיל CLI רשום, אך אינו מחובר כמנגנון גיבוי אוטומטי לספק.
  לשימוש אינטראקטיבי רגיל, הפעילו בעצמכם את ה-CLI המוגדר או
  השתמשו ב-`omniroute run`.

## דוגמאות לשילוב

### הצגת סוכני CLI מותקנים באמצעות ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### הוספת סוכן CLI מותאם אישית

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "ה-CLI המותאם אישית שלי",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

## מתי להשתמש במה

- **ממשק צ'אטבוט / טייס־משנה** → `/v1/chat/completions` (תואם OpenAI — אינו פרוטוקול סוכנים)
- **שיתוף פעולה בין מספר סוכנים** → A2A
- **הצגת ממשקי CLI מקומיים בלוח הבקרה** → ACP
- **האצלת משימות תכנות ארוכות־טווח לשירותי ענן** → סוכני ענן
