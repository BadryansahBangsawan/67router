OmniRoute ਏਜੰਟਾਂ ਨਾਲ ਸੰਬੰਧਿਤ ਤਿੰਨ ਵੱਖ-ਵੱਖ ਇੰਟਰਫੇਸ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ। ਪਹਿਲੀ ਨਜ਼ਰ ਵਿੱਚ ਇਹ ਇੱਕੋ ਜਿਹੇ ਲੱਗਦੇ ਹਨ, ਪਰ ਇਹ ਵੱਖ-ਵੱਖ ਸਮੱਸਿਆਵਾਂ ਹੱਲ ਕਰਦੇ ਹਨ। ਸਹੀ ਇੰਟਰਫੇਸ ਚੁਣਨ ਲਈ ਇਸ ਪੰਨੇ ਦੀ ਵਰਤੋਂ ਕਰੋ।

## ਸੰਖੇਪ ਵਿੱਚ

| ਇੰਟਰਫੇਸ                    | ਸਭ ਤੋਂ ਢੁਕਵਾਂ                                                                                                                            | ਟ੍ਰਾਂਸਪੋਰਟ                 | ਮਿਆਰ                    |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ----------------------- |
| **A2A — ਏਜੰਟ-ਤੋਂ-ਏਜੰਟ**    | A2A ਪ੍ਰੋਟੋਕੋਲ ਦੀ ਵਰਤੋਂ ਕਰਨ ਵਾਲੇ ਪੀਅਰ ਏਜੰਟਾਂ ਨਾਲ ਅੰਤਰ-ਏਜੰਟ ਸਹਿਯੋਗ                                                                         | HTTP ਉੱਤੇ JSON-RPC 2.0     | A2A v0.3 (ਖੁੱਲ੍ਹਾ ਮਿਆਰ) |
| **ACP — CLI ਏਜੰਟ ਰਜਿਸਟਰੀ** | ਉਪਭੋਗਤਾ ਦੀ ਮਸ਼ੀਨ ਉੱਤੇ ਇੰਸਟਾਲ ਕੀਤੇ CLI ਕੋਡਿੰਗ ਏਜੰਟਾਂ (Cursor, Cline, Codex CLI, Claude Code, Aider, ਆਦਿ) ਨੂੰ ਖੋਜਣਾ / ਰਜਿਸਟਰ ਕਰਨਾ / ਚਲਾਉਣਾ | HTTP REST                  | OmniRoute-ਵਿਸ਼ੇਸ਼       |
| **ਕਲਾਉਡ ਏਜੰਟ**             | ਲੰਬੇ ਸਮੇਂ ਤੱਕ ਚੱਲਣ ਵਾਲੇ ਕੋਡਿੰਗ ਕਾਰਜਾਂ ਨੂੰ ਬਾਹਰੀ ਕਲਾਉਡ ਸੇਵਾਵਾਂ (Codex Cloud, Devin, Jules, Cursor Cloud) ਨੂੰ ਸੌਂਪਣਾ                       | HTTP REST + DB-ਸਮਰਥਿਤ ਕਾਰਜ | OmniRoute-ਵਿਸ਼ੇਸ਼       |

## ਫ਼ੈਸਲਾ-ਰੁੱਖ

## 2. ACP — CLI ਏਜੰਟ ਰਜਿਸਟਰੀ

**OmniRoute ਐਂਡਪੌਇੰਟ:** `GET /api/acp/agents`
**ਸਰੋਤ:** `src/lib/acp/{index,manager,registry}.ts`

### ਇਹ ਕੀ ਹੈ

ACP, OmniRoute ਦੀ **ਸਥਾਨਕ CLI ਏਜੰਟ ਇਨਵੈਂਟਰੀ** ਹੈ। ਇਹ ਪਤਾ ਲਗਾਉਂਦੀ ਹੈ ਕਿ ਹੋਸਟ ਉੱਤੇ ਕਿਹੜੀਆਂ ਕੋਡਿੰਗ CLI ਇੰਸਟਾਲ ਹਨ (Cursor, Cline, Claude Code, Codex CLI, Continue ਆਦਿ), ਉਨ੍ਹਾਂ ਦੇ ਵਰਜਨ ਨਿਰਧਾਰਤ ਕਰਦੀ ਹੈ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ ਡੈਸ਼ਬੋਰਡ ਉੱਤੇ ਦਰਸਾਉਂਦੀ ਹੈ, ਤਾਂ ਜੋ ਵਰਤੋਂਕਾਰ ਹਰ CLI ਨੂੰ OmniRoute ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਨ ਲਈ ਕਨਫ਼ਿਗਰ ਕਰ ਸਕੇ।

HTTP ਇੰਟਰਫੇਸ ਇੱਕ ਅੰਦਰੂਨੀ ਇਨਵੈਂਟਰੀ ਹੈ ਜੋ "CLI Tools" UI ਅਤੇ
CLI ਫਿੰਗਰਪ੍ਰਿੰਟ ਟ੍ਰੈਕਿੰਗ ਨੂੰ ਚਲਾਉਂਦੀ ਹੈ ([CLI-TOOLS.md](../reference/CLI-TOOLS.md) ਵੇਖੋ)। ਇਸ ਤੋਂ ਵੱਖਰੇ ਤੌਰ ਉੱਤੇ,
ਅੰਦਰੂਨੀ ਪ੍ਰਕਿਰਿਆ ਮੈਨੇਜਰ ਰਜਿਸਟਰ ਕੀਤੇ Gemini ਲਾਂਚਰ ਲਈ ਮੂਲ Agent Client Protocol ਅਤੇ
ਹੋਰ ਕਾਂਟ੍ਰੈਕਟਾਂ ਲਈ ਪੁਰਾਣੇ stdio ਅਡੈਪਟਰਾਂ ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ।
ਇਨ੍ਹਾਂ ਵੱਖਰੇ ਮੋਡਾਂ ਅਤੇ ਸੀਮਾਵਾਂ ਲਈ [ACP ਰਜਿਸਟਰੀ ਅਤੇ ਲਾਂਚਰ](./ACP.md) ਵੇਖੋ।

### ਇਹ ਕੀ ਕਰਦਾ ਹੈ

- ਇੰਸਟਾਲ ਕੀਤੀਆਂ CLI ਬਾਈਨਰੀਆਂ ਲਈ ਹੋਸਟ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ (ਹਰੇਕ OS ਅਨੁਸਾਰ `which` / `where` ਵਰਤਦਾ ਹੈ)
- ਹਰ CLI ਦਾ ਵਰਜਨ ਪੜ੍ਹਦਾ ਹੈ (`<bin> --version` ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ)
- ਵਿਕਲਪਿਕ ਤੌਰ ਉੱਤੇ ਵਰਤੋਂਕਾਰ ਵੱਲੋਂ ਪਰਿਭਾਸ਼ਿਤ ਕਸਟਮ ਏਜੰਟ ਸਵੀਕਾਰ ਕਰਦਾ ਹੈ (ਬਾਈਨਰੀ ਪਾਥ + ਵਰਜਨ ਜਾਂਚ + ਸਪੌਨ ਆਰਗੂਮੈਂਟ)
- ਕਸਟਮ ਏਜੰਟਾਂ ਨੂੰ ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਸਥਾਈ ਤੌਰ ਉੱਤੇ ਸੰਭਾਲਦਾ ਹੈ
- ਡੈਸ਼ਬੋਰਡ ਨੂੰ ਇਕਸਾਰ ਸੂਚੀ ਵਾਪਸ ਕਰਦਾ ਹੈ

### REST API

| ਐਂਡਪੌਇੰਟ          | ਵਿਧੀ | ਵੇਰਵਾ                                                      | ਪ੍ਰਮਾਣੀਕਰਨ |
| ----------------- | ---- | ---------------------------------------------------------- | ---------- |
| `/api/acp/agents` | GET  | ਖੋਜੇ ਗਏ + ਕਸਟਮ ਏਜੰਟਾਂ ਦੀ ਸੂਚੀ (ਇੰਸਟਾਲ/ਕੁੱਲ ਗਿਣਤੀ)          | API ਕੁੰਜੀ  |
| `/api/acp/agents` | POST | ਕਸਟਮ ਏਜੰਟ ਜੋੜੋ/ਅੱਪਡੇਟ ਕਰੋ/ਹਟਾਓ (ਬਾਡੀ ਵਿੱਚ ਕਾਰਵਾਈ ਪਛਾਣਕਰਤਾ) | API ਕੁੰਜੀ  |

POST ਲਈ ਬਾਡੀ ਦੀ ਬਣਤਰ (`src/app/api/acp/agents/route.ts` ਵਿੱਚ `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ

- ਡੈਸ਼ਬੋਰਡ ਦਾ "CLI Tools" ਸਫ਼ਾ ਇੰਸਟਾਲ ਕੀਤੀਆਂ CLI ਦੀ ਸੂਚੀ ਦਿਖਾਉਂਦਾ ਹੈ ਅਤੇ ਹਰ ਇੱਕ ਨੂੰ OmniRoute ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਨ ਲਈ ਕਨਫ਼ਿਗਰ ਕਰਨ ਵਿੱਚ ਤੁਹਾਡੀ ਮਦਦ ਕਰਦਾ ਹੈ
- ਕਸਟਮ ਏਜੰਟ ਉੱਨਤ ਵਰਤੋਂਕਾਰਾਂ ਨੂੰ ਉਹ ਅੰਦਰੂਨੀ/ਮਲਕੀਅਤ ਵਾਲੀਆਂ CLI ਰਜਿਸਟਰ ਕਰਨ ਦਿੰਦੇ ਹਨ ਜਿਨ੍ਹਾਂ ਬਾਰੇ OmniRoute ਨੂੰ ਮੂਲ ਰੂਪ ਵਿੱਚ ਜਾਣਕਾਰੀ ਨਹੀਂ ਹੁੰਦੀ
- ਖੋਜ ਦਾ ਨਤੀਜਾ `cli-tools` ਫਿੰਗਰਪ੍ਰਿੰਟ ਮੈਟ੍ਰਿਕਸ ਨੂੰ ਡਾਟਾ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ

### ACP ਦੀ ਵਰਤੋਂ ਕਦੋਂ ਨਹੀਂ ਕਰਨੀ

- HTTP ਰਜਿਸਟਰੀ ਟਾਸਕ ਸਵੀਕਾਰ ਨਹੀਂ ਕਰਦੀ ਜਾਂ ਪ੍ਰਕਿਰਿਆ ਸਪੌਨਿੰਗ ਨੂੰ ਉਪਲਬਧ ਨਹੀਂ ਕਰਵਾਉਂਦੀ। ਅੰਦਰੂਨੀ
  ਮੈਨੇਜਰ ਇੱਕ ਰਜਿਸਟਰ ਕੀਤੀ CLI ਨੂੰ ਲਾਂਚ ਕਰ ਸਕਦਾ ਹੈ, ਪਰ ਇਸਨੂੰ ਸਵੈਚਾਲਿਤ ਪ੍ਰਦਾਤਾ
  ਫਾਲਬੈਕ ਵਜੋਂ ਜੋੜਿਆ ਨਹੀਂ ਗਿਆ ਹੈ। ਆਮ ਇੰਟਰਐਕਟਿਵ ਵਰਤੋਂ ਲਈ, ਕਨਫ਼ਿਗਰ ਕੀਤੀ CLI ਨੂੰ ਖੁਦ ਲਾਂਚ ਕਰੋ ਜਾਂ
  `omniroute run` ਵਰਤੋ।

## ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਉਦਾਹਰਨਾਂ

### ACP ਰਾਹੀਂ ਇੰਸਟਾਲ ਕੀਤੇ CLI ਏਜੰਟਾਂ ਦੀ ਸੂਚੀ ਪ੍ਰਾਪਤ ਕਰੋ

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### ਇੱਕ ਕਸਟਮ CLI ਏਜੰਟ ਸ਼ਾਮਲ ਕਰੋ

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```
