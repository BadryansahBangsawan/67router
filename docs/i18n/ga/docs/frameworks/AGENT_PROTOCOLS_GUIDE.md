> **Nuashonraithe go deireanach:** 2026-06-28 — v3.8.40

Cuireann OmniRoute trí chomhéadan éagsúla a bhaineann le gníomhairí ar fáil. Tá cuma chomhchosúil orthu ar an gcéad amharc, ach réitíonn siad fadhbanna éagsúla. Úsáid an leathanach seo chun an ceann ceart a roghnú.

## Go hachomair

| Comhéadan                          | Is fearr é le haghaidh                                                                                                                                   | Iompar                                             | Caighdeán                      |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------ |
| **A2A — Gníomhaire le Gníomhaire** | Comhoibriú idir gníomhairí le piarghníomhairí a úsáideann prótacal A2A                                                                                   | JSON-RPC 2.0 thar HTTP                             | A2A v0.3 (sonraíocht oscailte) |
| **ACP — Clárlann Gníomhairí CLI**  | Gníomhairí códúcháin CLI atá suiteáilte ar ríomhaire an úsáideora a bhrath / a chlárú / a lainseáil (Cursor, Cline, Codex CLI, Claude Code, Aider, etc.) | HTTP REST                                          | Sainiúil do OmniRoute          |
| **Gníomhairí Néalríomhaireachta**  | Tascanna códúcháin fadtréimhseacha a chur faoi bhráid seirbhísí seachtracha néalríomhaireachta (Codex Cloud, Devin, Jules, Cursor Cloud)                 | HTTP REST + tascanna le tacaíocht bunachair sonraí | Sainiúil do OmniRoute          |

Tá na trí cinn neamhspleách ar a chéile — roghnaigh aon fhothacar díobh.

## Crann Cinnidh

## 1. A2A — Gníomhaire le Gníomhaire

**Sonraíocht:** [A2A v0.3](https://a2a-protocol.org)
**Críochphointe OmniRoute:** `POST /a2a` (JSON-RPC 2.0)
**Cárta Gníomhaire:** `GET /.well-known/agent.json`

### Cathain ba cheart é a úsáid

- Córas ilghníomhaire a thógáil ina bhfuil OmniRoute ar cheann de na piaraí
- Faisnéis ródúcháin OmniRoute (ródú cliste, bainistiú cuótaí, etc.) a chur ar fáil do ghníomhairí i gcreataí amhail Google ADK nó i mogaill ghinearálta gníomhairí
- OmniRoute a fhilleadh taobh thiar de chomhéadan caighdeánach aimsithe + agartha

### Modhanna

- `message/send` — cuir teachtaireacht isteach agus faigh freagairt shioncrónach
- `message/stream` — cuir teachtaireacht isteach + faigh teagmhais dul chun cinn a shruthaítear trí SSE
- `tasks/get` — léigh tasc de réir a aitheantais
- `tasks/cancel` — cealaigh tasc atá ar siúl

### Scileanna ionsuite (6)

- `smart-routing` — ródáil leid tríd an teaglaim is fearr
- `quota-management` — tuairiscigh staid chuóta gach soláthraí
- `provider-discovery` — liostaigh soláthraithe suiteáilte agus a gcumais
- `cost-analysis` — déan costas iarratais/comhrá a mheas
- `health-report` — comhiomlánaigh staid scoradáin/tréimhse shuaimhnithe/frithdhúnadh gach soláthraí
- `list-capabilities` — liostaigh scileanna agus meiteashonraí an ghníomhaire atá ar fáil

### Mionscrúdú

Féach ar [A2A-SERVER.md](./A2A-SERVER.md) le haghaidh sonraí iompair, struchtúr an chárta gníomhaire, cumraíocht TTL na dtascanna, agus an teimpléad chun scileanna nua a chur leis.

## 2. ACP — Clárlann Gníomhairí CLI

**Críochphointe OmniRoute:** `GET /api/acp/agents`
**Foinse:** `src/lib/acp/{index,manager,registry}.ts`

### Céard atá ann

Is é ACP **fardal áitiúil gníomhairí CLI** OmniRoute. Aimsíonn sé cé na huirlisí CLI códaithe atá suiteáilte ar an óstríomhaire (Cursor, Cline, Claude Code, Codex CLI, Continue, srl.), cinneann sé a leaganacha, agus taispeánann sé iad ar an deais ionas gur féidir leis an úsáideoir gach CLI a chumrú chun OmniRoute a úsáid.

Is fardal inmheánach é an comhéadan HTTP a chumhachtaíonn an Chomhéadain "CLI Tools" agus
rianú méarloirg CLI (féach [CLI-TOOLS.md](../reference/CLI-TOOLS.md)). Ar leithligh uaidh sin,
tacaíonn an bainisteoir próisis inmheánach leis an Agent Client Protocol dúchasach don
tosaitheoir cláraithe Gemini agus le cuibheoirí stdio oidhreachta do chonarthaí eile.
Féach [Clárlann agus tosaitheoirí ACP](./ACP.md) le haghaidh na módanna agus na dteorainneacha ar leith sin.

### Céard a dhéanann sé

- Déanann sé iniúchadh ar an óstríomhaire le haghaidh dénárthaí CLI suiteáilte (úsáideann sé `which` / `where` de réir an chórais oibriúcháin)
- Léann sé leagan gach CLI (glaonn sé `<bin> --version`)
- Glacann sé, go roghnach, le gníomhairí saincheaptha atá sainithe ag an úsáideoir (cosán dénártha + brathadóireacht leagain + argóintí tionscanta)
- Coinníonn sé gníomhairí saincheaptha sna socruithe
- Seolann sé an liosta aontaithe ar ais chuig an deais

### API REST

| Críochphointe     | Modh | Cur síos                                                                                 | Fíordheimhniú |
| ----------------- | ---- | ---------------------------------------------------------------------------------------- | ------------- |
| `/api/acp/agents` | GET  | Liostaigh gníomhairí braite + saincheaptha (líon suiteáilte/iomlán)                      | Eochair API   |
| `/api/acp/agents` | POST | Cuir gníomhaire saincheaptha leis/nuashonraigh/bain é (idirdhealaitheoir gnímh sa chorp) | Eochair API   |

Cruth an choirp do POST (`customAgentBodySchema` in `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### Cásanna úsáide

- Liostaíonn leathanach "CLI Tools" na deaise a bhfuil suiteáilte agus cabhraíonn sé leat gach ceann acu a threorú chuig OmniRoute
- Ligeann gníomhairí saincheaptha d’ardúsáideoirí uirlisí CLI inmheánacha/dílseánaigh nach bhfuil OmniRoute ar an eolas fúthu de réir réamhshocraithe a chlárú
- Cuireann toradh an bhraite sonraí ar fáil don mhaitrís méarloirg `cli-tools`

### Cathain NÁ húsáid ACP

- Ní ghlacann clárlann HTTP le tascanna ná ní nochtann sí tionscnamh próiseas. Is féidir leis an mbainisteoir
  inmheánach CLI cláraithe a thosú, ach níl sé nasctha mar sholáthraí cúltaca
  uathoibríoch. Le haghaidh gnáthúsáide idirghníomhaí, tosaigh an CLI cumraithe tú féin nó
  úsáid `omniroute run`.

## Samplaí Comhtháthaithe

### Faigh amach cumais A2A OmniRoute

```bash
curl http://localhost:20128/.well-known/agent.json
```

Seolann sé an Cárta Gníomhaire ar ais leis na 6 scil, na hiompróirí agus an leagan go léir.

### Glaoigh ar OmniRoute mar ghníomhaire A2A

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### Liostaigh gníomhairí CLI suiteáilte trí ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### Cuir gníomhaire saincheaptha CLI leis

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

## Cathain is Ceart Gach Ceann a Úsáid

- **Comhéadan úsáideora róbhrá / comhphíolóta** → `/v1/chat/completions` (comhoiriúnach le OpenAI — ní prótacal gníomhaire é)
- **Comhoibriú ilghníomhairí** → A2A
- **CLIanna áitiúla a liostú sa deais** → ACP
- **Tascanna códúcháin fadtéarmacha a tharmligean chuig seirbhísí néalríomhaireachta** → Gníomhairí Néalríomhaireachta
