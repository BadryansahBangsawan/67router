67router முகவர்கள் தொடர்பான மூன்று வெவ்வேறு இடைமுகங்களை வழங்குகிறது. முதல் பார்வையில் அவை ஒரே மாதிரியாகத் தோன்றினாலும், வெவ்வேறு சிக்கல்களைத் தீர்க்கின்றன. சரியான ஒன்றைத் தேர்ந்தெடுக்க இந்தப் பக்கத்தைப் பயன்படுத்தவும்.

## சுருக்கமாக

| இடைமுகம்                            | இதற்கு மிகவும் ஏற்றது                                                                                                                                   | பரிமாற்ற முறை                        | தரநிலை                           |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | -------------------------------- |

| **ACP — CLI முகவர்கள் பதிவகம்**     | பயனரின் கணினியில் நிறுவப்பட்டுள்ள CLI நிரலாக்க முகவர்களைக் கண்டறிதல் / பதிவுசெய்தல் / தொடங்குதல் (Cursor, Cline, Codex CLI, Claude Code, Aider போன்றவை) | HTTP REST                            | 67router-க்கே உரியது             |

## முடிவு மரம்

## 2. ACP — CLI முகவர்கள் பதிவகம்

**67router முனைப்புள்ளி:** `GET /api/acp/agents`
**மூலம்:** `src/lib/acp/{index,manager,registry}.ts`

### இது என்ன

ACP என்பது 67router-இன் **உள்ளமை CLI முகவர் பட்டியல்** ஆகும். ஹோஸ்டில் நிறுவப்பட்டுள்ள நிரலாக்க CLI-களை (Cursor, Cline, Claude Code, Codex CLI, Continue போன்றவை) இது கண்டறிந்து, அவற்றின் பதிப்புகளைத் தீர்மானித்து, ஒவ்வொரு CLI-யும் 67router-ஐச் சுட்டிக்காட்டுமாறு பயனர் இணைக்க உதவுவதற்காக அவற்றை கட்டுப்பாட்டுப் பலகையில் காட்டுகிறது.

HTTP இடைமுகம் என்பது "CLI Tools" UI மற்றும்
CLI கைரேகைக் கண்காணிப்பை இயக்கும் ஓர் உள் பட்டியலாகும் ([CLI-TOOLS.md](../reference/CLI-TOOLS.md)-ஐப் பார்க்கவும்). தனியாக,
பதிவுசெய்யப்பட்ட Gemini துவக்கிக்கான இயல்பான Agent Client Protocol-ஐயும், பிற ஒப்பந்தங்களுக்கான மரபுவழி stdio அடாப்டர்களையும்
உள் செயல்முறை மேலாளர் ஆதரிக்கிறது.
அந்தத் தனித்தனி முறைகள் மற்றும் வரம்புகளுக்கு [ACP பதிவகம் மற்றும் துவக்கிகள்](./ACP.md)-ஐப் பார்க்கவும்.

### இது என்ன செய்கிறது

- நிறுவப்பட்ட CLI பைனரிகளுக்காக ஹோஸ்டைச் சோதிக்கிறது (OS-க்கு ஏற்ப `which` / `where` பயன்படுத்துகிறது)
- ஒவ்வொரு CLI-யின் பதிப்பையும் படிக்கிறது (`<bin> --version`-ஐ அழைக்கிறது)
- விருப்பத்திற்கேற்ப பயனர் வரையறுத்த தனிப்பயன் முகவர்களை ஏற்கிறது (பைனரி பாதை + பதிப்புச் சோதனை + தொடக்க அளவுருக்கள்)
- தனிப்பயன் முகவர்களை அமைப்புகளில் நிலையாகச் சேமிக்கிறது
- ஒருங்கிணைந்த பட்டியலைக் கட்டுப்பாட்டுப் பலகைக்குத் திருப்பி அளிக்கிறது

### REST API

| முனைப்புள்ளி      | முறை | விளக்கம்                                                                                | அங்கீகாரம் |
| ----------------- | ---- | --------------------------------------------------------------------------------------- | ---------- |
| `/api/acp/agents` | GET  | கண்டறியப்பட்ட + தனிப்பயன் முகவர்களைப் பட்டியலிடுகிறது (நிறுவப்பட்ட/மொத்த எண்ணிக்கைகள்)  | API விசை   |
| `/api/acp/agents` | POST | தனிப்பயன் முகவரைச் சேர்க்கிறது/புதுப்பிக்கிறது/நீக்குகிறது (body-இல் செயல் வேறுபடுத்தி) | API விசை   |

POST-க்கான body வடிவம் (`src/app/api/acp/agents/route.ts`-இல் உள்ள `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### பயன்பாடுகள்

- கட்டுப்பாட்டுப் பலகையின் "CLI Tools" பக்கம் நிறுவப்பட்டுள்ளவற்றைப் பட்டியலிட்டு, ஒவ்வொன்றையும் 67router-ஐச் சுட்டிக்காட்டுமாறு அமைக்க உதவுகிறது
- 67router இயல்பாக அறியாத உள்/தனியுரிம CLI-களை மேம்பட்ட பயனர்கள் பதிவுசெய்ய தனிப்பயன் முகவர்கள் உதவுகின்றன
- கண்டறிதல் முடிவு `cli-tools` கைரேகை அணியைத் தரவூட்டுகிறது

### ACP-ஐப் பயன்படுத்தக் கூடாத சூழல்கள்

- HTTP பதிவகம் பணிகளை ஏற்காது அல்லது செயல்முறை தொடக்கத்தை வெளிப்படுத்தாது. உள்
  மேலாளர் பதிவுசெய்யப்பட்ட CLI ஒன்றைத் தொடங்க முடியும், ஆனால் அது தானியங்கி வழங்குநர்
  மாற்றுவழியாக இணைக்கப்படவில்லை. வழக்கமான ஊடாடும் பயன்பாட்டிற்கு, உள்ளமைக்கப்பட்ட CLI-ஐ நீங்களே தொடங்கவும் அல்லது
  `omniroute run`-ஐப் பயன்படுத்தவும்.

## ஒருங்கிணைப்பு எடுத்துக்காட்டுகள்

### ACP வழியாக நிறுவப்பட்ட CLI முகவர்களைப் பட்டியலிடுதல்

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### தனிப்பயன் CLI முகவரைச் சேர்த்தல்

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

## எதை எப்போது பயன்படுத்த வேண்டும்

- **Chatbot / copilot முன்தளம்** → `/v1/chat/completions` (OpenAI-இணக்கமானது — முகவர் நெறிமுறை அல்ல)
- **பல முகவர் கூட்டுப்பணி** → A2A
- **முகப்புப் பலகையில் உள்ளூர் CLI-களைப் பட்டியலிடுதல்** → ACP
- **நீண்ட நேரம் இயங்கும் நிரலாக்கப் பணிகளை Cloud சேவைகளுக்கு ஒப்படைத்தல்** → Cloud Agents
