OmniRoute ఏజెంట్లకు సంబంధించిన మూడు విభిన్న ఇంటర్ఫేస్లను అందిస్తుంది. మొదటి చూపులో అవి ఒకేలా కనిపించినప్పటికీ, విభిన్న సమస్యలను పరిష్కరిస్తాయి. సరైనదాన్ని ఎంచుకోవడానికి ఈ పేజీని ఉపయోగించండి.

## సంక్షిప్తంగా

| ఇంటర్ఫేస్                        | దీనికి అత్యుత్తమం                                                                                                                                          | రవాణా విధానం                   | ప్రమాణం                 |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ----------------------- |
| **A2A — ఏజెంట్-టు-ఏజెంట్**       | A2A ప్రోటోకాల్ను ఉపయోగించే పీర్ ఏజెంట్లతో ఏజెంట్ల మధ్య సహకారం                                                                                              | HTTP ద్వారా JSON-RPC 2.0       | A2A v0.3 (ఓపెన్ స్పెక్) |
| **ACP — CLI ఏజెంట్ల రిజిస్ట్రీ** | వినియోగదారు మెషీన్లో ఇన్స్టాల్ చేసిన CLI కోడింగ్ ఏజెంట్లను గుర్తించడం / నమోదు చేయడం / ప్రారంభించడం (Cursor, Cline, Codex CLI, Claude Code, Aider మొదలైనవి) | HTTP REST                      | OmniRoute-ప్రత్యేకం     |
| **క్లౌడ్ ఏజెంట్లు**              | దీర్ఘకాలం నడిచే కోడింగ్ టాస్క్లను బాహ్య క్లౌడ్ సేవలకు సమర్పించడం (Codex Cloud, Devin, Jules, Cursor Cloud)                                                 | HTTP REST + DB-ఆధారిత టాస్క్లు | OmniRoute-ప్రత్యేకం     |

ఈ మూడు స్వతంత్రమైనవి — వీటిలో ఏ ఉపసమితినైనా ఎంచుకోండి.

## నిర్ణయ వృక్షం

## 2. ACP — CLI ఏజెంట్ల రిజిస్ట్రీ

**OmniRoute ఎండ్పాయింట్:** `GET /api/acp/agents`
**మూలం:** `src/lib/acp/{index,manager,registry}.ts`

### ఇది ఏమిటి

ACP అనేది OmniRoute యొక్క **స్థానిక CLI ఏజెంట్ ఇన్వెంటరీ**. ఇది హోస్ట్లో ఏ కోడింగ్ CLIలు ఇన్స్టాల్ చేయబడ్డాయో (Cursor, Cline, Claude Code, Codex CLI, Continue మొదలైనవి) గుర్తించి, వాటి వెర్షన్లను నిర్ధారించి, ప్రతి CLIని OmniRouteకు అనుసంధానించేలా వినియోగదారు కాన్ఫిగర్ చేసేందుకు వాటిని డ్యాష్బోర్డ్లో చూపిస్తుంది.

HTTP ఉపరితలం అనేది "CLI Tools" UI మరియు CLI ఫింగర్ప్రింట్ ట్రాకింగ్కు శక్తినిచ్చే అంతర్గత ఇన్వెంటరీ
([CLI-TOOLS.md](../reference/CLI-TOOLS.md) చూడండి). దీనికి విడిగా, అంతర్గత ప్రాసెస్ మేనేజర్
నమోదు చేసిన Gemini లాంచర్ కోసం స్థానిక Agent Client Protocolకు మరియు ఇతర ఒప్పందాల కోసం
లెగసీ stdio అడాప్టర్లకు మద్దతు ఇస్తుంది.
ఆ విభిన్న మోడ్లు మరియు పరిమితుల కోసం [ACP రిజిస్ట్రీ మరియు లాంచర్లు](./ACP.md) చూడండి.

### ఇది ఏమి చేస్తుంది

- ఇన్స్టాల్ చేసిన CLI బైనరీల కోసం హోస్ట్ను పరిశీలిస్తుంది (OSను బట్టి `which` / `where` ఉపయోగిస్తుంది)
- ప్రతి CLI వెర్షన్ను చదువుతుంది (`<bin> --version`ను కాల్ చేస్తుంది)
- ఐచ్ఛికంగా వినియోగదారు నిర్వచించిన కస్టమ్ ఏజెంట్లను ఆమోదిస్తుంది (బైనరీ పాత్ + వెర్షన్ ప్రోబ్ + స్పాన్ ఆర్గ్యుమెంట్లు)
- కస్టమ్ ఏజెంట్లను సెట్టింగ్లలో స్థిరంగా భద్రపరుస్తుంది
- ఏకీకృత జాబితాను డ్యాష్బోర్డ్కు అందిస్తుంది

### REST API

| ఎండ్పాయింట్       | పద్ధతి | వివరణ                                                                          | ప్రామాణీకరణ |
| ----------------- | ------ | ------------------------------------------------------------------------------ | ----------- |
| `/api/acp/agents` | GET    | గుర్తించిన + కస్టమ్ ఏజెంట్ల జాబితా (ఇన్స్టాల్ చేసినవి/మొత్తం సంఖ్యలు)          | API కీ      |
| `/api/acp/agents` | POST   | కస్టమ్ ఏజెంట్ను జోడించడం/నవీకరించడం/తొలగించడం (బాడీలో యాక్షన్ డిస్క్రిమినేటర్) | API కీ      |

POST కోసం బాడీ ఆకృతి (`src/app/api/acp/agents/route.ts`లోని `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### వినియోగ సందర్భాలు

- డ్యాష్బోర్డ్లోని "CLI Tools" పేజీ ఇన్స్టాల్ చేసిన వాటిని జాబితా చేసి, ప్రతిదానినీ OmniRouteకు అనుసంధానించడంలో మీకు సహాయపడుతుంది
- OmniRouteకు డిఫాల్ట్గా తెలియని అంతర్గత/యాజమాన్య CLIలను నిపుణ వినియోగదారులు నమోదు చేసుకోవడానికి కస్టమ్ ఏజెంట్లు వీలు కల్పిస్తాయి
- గుర్తింపు ఫలితం `cli-tools` ఫింగర్ప్రింట్ మ్యాట్రిక్స్కు డేటాను అందిస్తుంది

### ACPని ఎప్పుడు ఉపయోగించకూడదు

- HTTP రిజిస్ట్రీ టాస్క్లను ఆమోదించదు లేదా ప్రాసెస్ స్పానింగ్ను అందుబాటులో ఉంచదు. అంతర్గత
  మేనేజర్ నమోదు చేసిన CLIని ప్రారంభించగలదు, కానీ అది ఆటోమేటిక్ ప్రొవైడర్
  ఫాల్బ్యాక్గా అనుసంధానించబడలేదు. సాధారణ ఇంటరాక్టివ్ వినియోగం కోసం, కాన్ఫిగర్ చేసిన CLIని మీరే ప్రారంభించండి లేదా
  `omniroute run` ఉపయోగించండి.

## ఇంటిగ్రేషన్ ఉదాహరణలు

### ACP ద్వారా ఇన్స్టాల్ చేసిన CLI ఏజెంట్లను జాబితా చేయండి

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### కస్టమ్ CLI ఏజెంట్ను జోడించండి

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

## దేనిని ఎప్పుడు ఉపయోగించాలి

- **Chatbot / copilot ఫ్రంటెండ్** → `/v1/chat/completions` (OpenAI-అనుకూలం — ఇది ఏజెంట్ ప్రోటోకాల్ కాదు)
- **మల్టీ-ఏజెంట్ సహకారం** → A2A
- **డ్యాష్బోర్డ్లో స్థానిక CLIలను జాబితా చేయడం** → ACP
- **దీర్ఘకాలం నడిచే కోడింగ్ టాస్క్లను క్లౌడ్ సేవలకు అప్పగించడం** → Cloud Agents
