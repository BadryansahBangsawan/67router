> **Cập nhật lần cuối:** 2026-06-28 — v3.8.40

67router cung cấp ba giao diện khác nhau liên quan đến agent. Thoạt nhìn, chúng có vẻ giống nhau nhưng giải quyết các vấn đề khác nhau. Hãy sử dụng trang này để chọn giao diện phù hợp.

## Tóm tắt nhanh

| Giao diện                     | Phù hợp nhất cho                                                                                                                                  | Phương thức truyền tải         | Tiêu chuẩn              |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ----------------------- |
| **A2A — Agent-to-Agent**      | Cộng tác liên agent với các agent ngang hàng hỗ trợ giao thức A2A                                                                                 | JSON-RPC 2.0 qua HTTP          | A2A v0.3 (đặc tả mở)    |
| **ACP — CLI Agents Registry** | Phát hiện / đăng ký / khởi chạy các agent lập trình CLI được cài đặt trên máy của người dùng (Cursor, Cline, Codex CLI, Claude Code, Aider, v.v.) | HTTP REST                      | Dành riêng cho 67router |
| **Cloud Agents**              | Gửi các tác vụ lập trình kéo dài đến các dịch vụ đám mây bên ngoài (Codex Cloud, Devin, Jules, Cursor Cloud)                                      | HTTP REST + tác vụ lưu trên DB | Dành riêng cho 67router |

Cả ba đều độc lập — có thể chọn bất kỳ tập hợp con nào.

## Cây quyết định

## 2. ACP — Sổ đăng ký tác nhân CLI

**Điểm cuối 67router:** `GET /api/acp/agents`
**Nguồn:** `src/lib/acp/{index,manager,registry}.ts`

### Đây là gì

ACP là **kho tác nhân CLI cục bộ** của 67router. Nó phát hiện các CLI lập trình được cài đặt trên máy chủ (Cursor, Cline, Claude Code, Codex CLI, Continue, v.v.), xác định phiên bản của chúng và hiển thị chúng trên bảng điều khiển để người dùng có thể cấu hình từng CLI trỏ đến 67router.

Giao diện HTTP là một kho nội bộ hỗ trợ giao diện người dùng "CLI Tools" và
việc theo dõi dấu vân tay CLI (xem [CLI-TOOLS.md](../reference/CLI-TOOLS.md)). Ngoài ra,
trình quản lý tiến trình nội bộ hỗ trợ Agent Client Protocol gốc cho trình khởi chạy
Gemini đã đăng ký và các bộ điều hợp stdio cũ cho những giao thức khác.
Xem [sổ đăng ký và trình khởi chạy ACP](./ACP.md) để biết các chế độ và giới hạn riêng biệt này.

### Chức năng

- Kiểm tra máy chủ để tìm các tệp nhị phân CLI đã cài đặt (sử dụng `which` / `where` tùy theo hệ điều hành)
- Đọc phiên bản của từng CLI (gọi `<bin> --version`)
- Tùy chọn chấp nhận các tác nhân tùy chỉnh do người dùng định nghĩa (đường dẫn tệp nhị phân + lệnh kiểm tra phiên bản + các đối số khởi tạo tiến trình)
- Lưu trữ lâu dài các tác nhân tùy chỉnh trong phần cài đặt
- Trả về danh sách hợp nhất cho bảng điều khiển

### API REST

| Điểm cuối         | Phương thức | Mô tả                                                                             | Xác thực |
| ----------------- | ----------- | --------------------------------------------------------------------------------- | -------- |
| `/api/acp/agents` | GET         | Liệt kê các tác nhân được phát hiện + tùy chỉnh (số lượng đã cài đặt/tổng số)     | Khóa API |
| `/api/acp/agents` | POST        | Thêm/cập nhật/xóa tác nhân tùy chỉnh (trường phân biệt hành động trong phần thân) | Khóa API |

Cấu trúc phần thân cho POST (`customAgentBodySchema` trong `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### Trường hợp sử dụng

- Trang "CLI Tools" trên bảng điều khiển liệt kê những công cụ đã được cài đặt và giúp bạn cấu hình từng công cụ trỏ đến 67router
- Tác nhân tùy chỉnh cho phép người dùng nâng cao đăng ký các CLI nội bộ/độc quyền mà 67router không nhận biết theo mặc định
- Kết quả phát hiện cung cấp dữ liệu cho ma trận dấu vân tay `cli-tools`

### Khi KHÔNG nên sử dụng ACP

- Sổ đăng ký HTTP không tiếp nhận tác vụ hoặc cung cấp khả năng khởi tạo tiến trình. Trình quản lý
  nội bộ có thể khởi chạy một CLI đã đăng ký, nhưng không được kết nối để tự động làm phương án
  dự phòng cho nhà cung cấp. Đối với việc sử dụng tương tác thông thường, hãy tự khởi chạy CLI đã cấu hình hoặc
  sử dụng `omniroute run`.

## Ví dụ tích hợp

### Liệt kê các tác nhân CLI đã cài đặt thông qua ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### Thêm một tác nhân CLI tùy chỉnh

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "CLI tùy chỉnh của tôi",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

## Khi nào nên sử dụng giải pháp nào

- **Giao diện chatbot / copilot** → `/v1/chat/completions` (tương thích OpenAI — không phải giao thức tác nhân)
- **Cộng tác đa tác nhân** → A2A
- **Liệt kê các CLI cục bộ trong bảng điều khiển** → ACP
- **Ủy quyền các tác vụ lập trình chạy trong thời gian dài cho dịch vụ đám mây** → Cloud Agents
