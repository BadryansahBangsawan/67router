## ନିଷ୍ପତ୍ତି ବୃକ୍ଷ

## 2. ACP — CLI ଏଜେଣ୍ଟ ରେଜିଷ୍ଟ୍ରି

**67router ଏଣ୍ଡପଏଣ୍ଟ:** `GET /api/acp/agents`
**ଉତ୍ସ:** `src/lib/acp/{index,manager,registry}.ts`

### ଏହା କ’ଣ

ACP ହେଉଛି 67routerର **ସ୍ଥାନୀୟ CLI ଏଜେଣ୍ଟ ତାଲିକା**। ଏହା ହୋଷ୍ଟରେ କେଉଁ କୋଡିଂ CLIଗୁଡ଼ିକ ଇନଷ୍ଟଲ୍ ହୋଇଛି (Cursor, Cline, Claude Code, Codex CLI, Continue ଇତ୍ୟାଦି) ଚିହ୍ନଟ କରେ, ସେଗୁଡ଼ିକର ସଂସ୍କରଣ ନିର୍ଦ୍ଧାରଣ କରେ ଏବଂ ଡ୍ୟାସ୍ବୋର୍ଡରେ ପ୍ରଦର୍ଶନ କରେ, ଯାହାଦ୍ୱାରା ଉପଯୋଗକର୍ତ୍ତା ପ୍ରତ୍ୟେକ CLIକୁ 67router ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶ କରିବା ପାଇଁ ସଂଯୋଜନ କରିପାରିବେ।

HTTP ପୃଷ୍ଠଟି ହେଉଛି ଏକ ଆଭ୍ୟନ୍ତରୀଣ ତାଲିକା, ଯାହା "CLI Tools" UI ଏବଂ
CLI ଫିଙ୍ଗରପ୍ରିଣ୍ଟ ଟ୍ରାକିଂକୁ ସଞ୍ଚାଳିତ କରେ ([CLI-TOOLS.md](../reference/CLI-TOOLS.md) ଦେଖନ୍ତୁ)। ପୃଥକ ଭାବରେ,
ଆଭ୍ୟନ୍ତରୀଣ ପ୍ରକ୍ରିୟା ପରିଚାଳକ ପଞ୍ଜୀକୃତ Gemini ଲଞ୍ଚର୍ ପାଇଁ ନେଟିଭ୍ Agent Client Protocol ଏବଂ ଅନ୍ୟ ଚୁକ୍ତିଗୁଡ଼ିକ ପାଇଁ ପୁରୁଣା stdio ଆଡାପ୍ଟର୍ଗୁଡ଼ିକୁ ସମର୍ଥନ କରେ।
ସେହି ଭିନ୍ନ ମୋଡ୍ ଏବଂ ସୀମାଗୁଡ଼ିକ ପାଇଁ [ACP ରେଜିଷ୍ଟ୍ରି ଏବଂ ଲଞ୍ଚର୍ଗୁଡ଼ିକ](./ACP.md) ଦେଖନ୍ତୁ।

### ଏହା କ’ଣ କରେ

- ଇନଷ୍ଟଲ୍ ହୋଇଥିବା CLI ବାଇନାରିଗୁଡ଼ିକ ପାଇଁ ହୋଷ୍ଟକୁ ଯାଞ୍ଚ କରେ (OS ଅନୁଯାୟୀ `which` / `where` ବ୍ୟବହାର କରେ)
- ପ୍ରତ୍ୟେକ CLIର ସଂସ୍କରଣ ପଢ଼େ (`<bin> --version`କୁ କଲ୍ କରେ)
- ଇଚ୍ଛାନୁସାରେ ଉପଯୋଗକର୍ତ୍ତା-ନିର୍ଦ୍ଧାରିତ କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକୁ ଗ୍ରହଣ କରେ (ବାଇନାରି ପଥ + ସଂସ୍କରଣ ଯାଞ୍ଚ + ସ୍ପନ୍ ଆର୍ଗୁମେଣ୍ଟ)
- ସେଟିଂସ୍ରେ କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକୁ ସ୍ଥାୟୀ ଭାବେ ସଂରକ୍ଷଣ କରେ
- ଡ୍ୟାସ୍ବୋର୍ଡକୁ ଏକୀକୃତ ତାଲିକା ଫେରାଏ

### REST API

| ଏଣ୍ଡପଏଣ୍ଟ         | ପଦ୍ଧତି | ବର୍ଣ୍ଣନା                                                                          | ପ୍ରାମାଣିକରଣ |
| ----------------- | ------ | --------------------------------------------------------------------------------- | ----------- |
| `/api/acp/agents` | GET    | ଚିହ୍ନଟ ହୋଇଥିବା + କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକର ତାଲିକା (ଇନଷ୍ଟଲ୍ ହୋଇଥିବା/ମୋଟ ସଂଖ୍ୟା)         | API କି      |
| `/api/acp/agents` | POST   | କଷ୍ଟମ୍ ଏଜେଣ୍ଟ ଯୋଡ଼ନ୍ତୁ/ଅଦ୍ୟତନ କରନ୍ତୁ/ଅପସାରଣ କରନ୍ତୁ (ବଡିରେ ଆକ୍ସନ୍ ଡିସ୍କ୍ରିମିନେଟର୍) | API କି      |

POST ପାଇଁ ବଡିର ଗଠନ (`src/app/api/acp/agents/route.ts`ରେ `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### ବ୍ୟବହାର କ୍ଷେତ୍ର

- ଡ୍ୟାସ୍ବୋର୍ଡର "CLI Tools" ପୃଷ୍ଠା କ’ଣ ଇନଷ୍ଟଲ୍ ହୋଇଛି ତାହା ତାଲିକାଭୁକ୍ତ କରେ ଏବଂ ପ୍ରତ୍ୟେକକୁ 67router ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶ କରିବାରେ ଆପଣଙ୍କୁ ସାହାଯ୍ୟ କରେ
- କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକ ଉନ୍ନତ ଉପଯୋଗକର୍ତ୍ତାଙ୍କୁ ଏପରି ଆଭ୍ୟନ୍ତରୀଣ/ମାଲିକାନାଧୀନ CLIଗୁଡ଼ିକ ପଞ୍ଜୀକୃତ କରିବାକୁ ଦିଅନ୍ତି, ଯାହା ବିଷୟରେ 67router ଡିଫଲ୍ଟ ଭାବରେ ଜାଣେ ନାହିଁ
- ଚିହ୍ନଟ ଫଳାଫଳ `cli-tools` ଫିଙ୍ଗରପ୍ରିଣ୍ଟ ମ୍ୟାଟ୍ରିକ୍ସକୁ ତଥ୍ୟ ଯୋଗାଏ

### କେତେବେଳେ ACP ବ୍ୟବହାର କରିବେ ନାହିଁ

- HTTP ରେଜିଷ୍ଟ୍ରି କାର୍ଯ୍ୟଗୁଡ଼ିକୁ ଗ୍ରହଣ କରେ ନାହିଁ କିମ୍ବା ପ୍ରକ୍ରିୟା ସ୍ପନିଂକୁ ଉନ୍ମୋଚନ କରେ ନାହିଁ। ଆଭ୍ୟନ୍ତରୀଣ
  ପରିଚାଳକ ଏକ ପଞ୍ଜୀକୃତ CLIକୁ ଚାଲୁ କରିପାରେ, କିନ୍ତୁ ଏହାକୁ ଏକ ସ୍ୱୟଂଚାଳିତ ପ୍ରଦାନକାରୀ
  ଫଲ୍ବ୍ୟାକ୍ ଭାବେ ସଂଯୋଜିତ କରାଯାଇନାହିଁ। ସାଧାରଣ ଇଣ୍ଟରାକ୍ଟିଭ୍ ବ୍ୟବହାର ପାଇଁ, ବିନ୍ୟାସିତ CLIକୁ ନିଜେ ଚାଲୁ କରନ୍ତୁ କିମ୍ବା
  `omniroute run` ବ୍ୟବହାର କରନ୍ତୁ।

## ଇଣ୍ଟିଗ୍ରେସନ୍ ଉଦାହରଣ

### ACP ମାଧ୍ୟମରେ ଇନ୍ଷ୍ଟଲ୍ ହୋଇଥିବା CLI ଏଜେଣ୍ଟଗୁଡ଼ିକର ତାଲିକା ଦେଖନ୍ତୁ

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### ଏକ କଷ୍ଟମ୍ CLI ଏଜେଣ୍ଟ ଯୋଡ଼ନ୍ତୁ

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
```
