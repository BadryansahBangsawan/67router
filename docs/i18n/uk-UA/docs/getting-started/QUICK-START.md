## Крок 1: Установіть 67router

Виберіть зручний для вас спосіб:

### Варіант A: npm (рекомендовано)

```bash
npm install -g omniroute
```

### Варіант B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` — це найвища **опублікована** стабільна версія SemVer. Цей тег **не** відстежує гілку git `main`. Для GitOps зафіксуйте `diegosouzapw/omniroute:X.Y.Z`. Див. [Теги образів / Канали випусків](../guides/DOCKER_GUIDE.md#release-channels).

### Варіант C: з вихідного коду

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Крок 2: Запустіть 67router

```bash
omniroute
```

67router запускається за адресою `http://localhost:20128`. Панель керування відкриється автоматично.

---

## Крок 3: Підключіть відповідного провайдера

Виберіть провайдера, умови та квота якого відповідають вашим потребам. У розділі **Панель керування → Провайдери** підключіть власний обліковий запис або API-ключ, а потім перевірте з’єднання. Безкоштовний доступ і можливість використання без ключа не гарантуються.

За замовчуванням `auto` виключає провайдерів із позначкою `tos: avoid`, зокрема Kiro. Підключення облікового запису не змінює цю політику. Згода в розділі **Панель керування → Комбінації** застосовується до всіх автоматичних комбінацій. Перш ніж вибрати провайдера, ознайомтеся з [Посібником із безкоштовних рівнів](./FREE-TIERS-GUIDE.md).

---

## Крок 4: Перевірте, чи все працює

У розділі [API-ключі](http://localhost:20128/dashboard/api-manager) створіть новий ключ. Збережіть його, оскільки він більше не відображатиметься. Зверніть увагу: цей ключ потрібен інструментам для доступу до 67router, а не для доступу до зовнішніх провайдерів.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ви маєте побачити список підключених моделей.

---

## Крок 5: Спрямуйте свою IDE або CLI до 67router

У своїй IDE або CLI-утиліті задайте:

```
Базова URL-адреса: http://localhost:20128/v1
API-ключ:           [скопіюйте з Панелі керування → Кінцеві точки]
Модель:             auto
```

Ось і все! Тепер ваша IDE використовує 67router з автоматичним вибором провайдера.

### Приклад для IDE: VSCode/Continue.dev

1. У VSCode встановіть розширення [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Оновіть свій файл `~/.continue/config.yaml`, додавши такі рядки:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. На панелі чату Continue.dev виберіть `OmniRoute - Auto`, після чого запити надсилатимуться до 67router.
4. (Необов'язково) Вправа для читача: попросіть свою IDE доповнити `config.yaml` усіма іншими готовими конфігураціями 😊

### Приклад для CLI: Codex CLI

1. У своїй операційній системі задайте змінну середовища на постійній основі.
   Для macOS/Linux (додайте до `~/.bashrc` або `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Для Windows (командний рядок):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Тепер запустімо Codex, налаштований для 67router. Виконайте:

```
omniroute launch-codex --model auto
```

Це можна зробити вручну через `codex` і параметри командного рядка, указавши кінцеву точку та API-ключ, але з наведеною вище командою 67router подбає про все за вас.

Такий самий запуск однією командою працює для інших CLI через універсальний засіб запуску — `omniroute run <target>` підтримує `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` і `gemini` (див. [Інтеграції CLI](../guides/CLI-INTEGRATIONS.md)).

3. Тепер CLI має надсилати запити до 67router.

### Переконайтеся, що ваш інструмент маршрутизує запити до 67router

Докладні відомості про запит можна переглянути, натиснувши [Моніторинг/Журнали](http://localhost:20128/dashboard/logs) на лівій бічній панелі. Перейшовши до запису, ви побачите додаткові подробиці. Також можна переглянути, яку інформацію надсилає ваше улюблене середовище. Це корисно для навчання та налагодження.

## Поширені запитання

### «Чи потрібен мені ключ API?»

Ключ API 67router автентифікує ваші інструменти. Облікові дані для зовнішніх сервісів залежать від провайдера: деякі вимагають ключ API або вхід в обліковий запис. Безкоштовний доступ не гарантується.

### «Що таке `auto`?»

`auto` вказує 67router автоматично вибирати найкращого провайдера для кожного запиту. Враховуються швидкість, вартість, якість і доступність. Докладніше див. у [посібнику з Auto-Combo](./AUTO-COMBO-GUIDE.md).

### «Скільки це коштує?»

Сам 67router — **безкоштовний проєкт із відкритим вихідним кодом**. Ви платите лише за провайдерів, яких використовуєте. Багато провайдерів мають безкоштовні тарифні плани — див. [посібник із безкоштовних тарифних планів](./FREE-TIERS-GUIDE.md).

### «Чи можна використовувати його з Claude Code / Cursor / Copilot?»

**Так!** 67router працює з будь-яким інструментом, що підтримує формат OpenAI. Просто встановіть базову URL-адресу `http://localhost:20128/v1`. Конкретні інструкції з налаштування див. у [посібнику з інструментів CLI](../reference/CLI-TOOLS.md).

### «Що станеться, якщо провайдер припинить роботу?»

67router автоматично пропускає провайдерів, під час роботи з якими виникла помилка, і намагається використати наступного. Вам не потрібно нічого робити. Докладніше див. у [посібнику з Auto-Combo](./AUTO-COMBO-GUIDE.md).
