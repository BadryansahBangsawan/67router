> **آخر تحديث:** 2026-06-28 — v3.8.40

يوفّر 67router ثلاث واجهات مختلفة مرتبطة بالوكلاء. قد تبدو متشابهة للوهلة الأولى، لكنها تحل مشكلات مختلفة. استخدم هذه الصفحة لاختيار الواجهة المناسبة.

## الخلاصة

| الواجهة                    | الأنسب لـ                                                                                                                           | وسيلة النقل                           | المعيار                  |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- | ------------------------ |
| **A2A — من وكيل إلى وكيل** | التعاون بين الوكلاء مع وكلاء نظراء يدعمون بروتوكول A2A                                                                              | JSON-RPC 2.0 عبر HTTP                 | A2A v0.3 (مواصفة مفتوحة) |
| **ACP — سجل وكلاء CLI**    | اكتشاف / تسجيل / تشغيل وكلاء البرمجة عبر CLI المثبّتين على جهاز المستخدم (Cursor، وCline، وCodex CLI، وClaude Code، وAider، وغيرها) | HTTP REST                             | خاص بـ 67router          |
| **الوكلاء السحابيون**      | إرسال مهام برمجية طويلة الأمد إلى خدمات سحابية خارجية (Codex Cloud، وDevin، وJules، وCursor Cloud)                                  | HTTP REST + مهام مدعومة بقاعدة بيانات | خاص بـ 67router          |

هذه الواجهات الثلاث مستقلة — اختر أي مجموعة فرعية منها.

## شجرة القرار

## 2. ACP — سجل وكلاء CLI

**نقطة نهاية 67router:** `GET /api/acp/agents`
**المصدر:** `src/lib/acp/{index,manager,registry}.ts`

### ما هو

يمثّل ACP **مخزون وكلاء CLI المحليين** في 67router. يكتشف أدوات CLI البرمجية المثبّتة على المضيف (Cursor وCline وClaude Code وCodex CLI وContinue وغيرها)، ويحدّد إصداراتها، ويعرضها في لوحة المعلومات حتى يتمكن المستخدم من تهيئة كل أداة CLI للإشارة إلى 67router.

واجهة HTTP عبارة عن مخزون داخلي يشغّل واجهة مستخدم "أدوات CLI"
وتتبّع بصمات CLI (راجع [CLI-TOOLS.md](../reference/CLI-TOOLS.md)). وبشكل منفصل،
يدعم مدير العمليات الداخلي بروتوكول Agent Client Protocol الأصلي لمشغّل Gemini
المسجّل، ومحوّلات stdio القديمة للعقود الأخرى.
راجع [سجل ACP والمشغّلات](./ACP.md) للاطلاع على هذه الأوضاع والقيود المختلفة.

### ما الذي يفعله

- يفحص المضيف بحثًا عن ملفات CLI التنفيذية المثبّتة (باستخدام `which` / `where` وفقًا لنظام التشغيل)
- يقرأ إصدار كل أداة CLI (عن طريق استدعاء `<bin> --version`)
- يقبل اختياريًا وكلاء مخصّصين يعرّفهم المستخدم (مسار الملف التنفيذي + فحص الإصدار + وسائط التشغيل)
- يحفظ الوكلاء المخصّصين بشكل دائم في الإعدادات
- يعيد القائمة الموحّدة إلى لوحة المعلومات

### واجهة REST API

| نقطة النهاية      | الطريقة | الوصف                                                     | المصادقة  |
| ----------------- | ------- | --------------------------------------------------------- | --------- |
| `/api/acp/agents` | GET     | عرض الوكلاء المكتشفين والمخصّصين (أعداد المثبّت/الإجمالي) | مفتاح API |
| `/api/acp/agents` | POST    | إضافة/تحديث/إزالة وكيل مخصّص (مميّز الإجراء في نص الطلب)  | مفتاح API |

بنية نص طلب POST (`customAgentBodySchema` في `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### حالات الاستخدام

- تعرض صفحة "أدوات CLI" في لوحة المعلومات الأدوات المثبّتة وتساعدك على توجيه كل منها إلى 67router
- يتيح الوكلاء المخصّصون للمستخدمين المتقدّمين تسجيل أدوات CLI داخلية/احتكارية لا يعرفها 67router افتراضيًا
- تغذّي نتيجة الاكتشاف مصفوفة بصمات `cli-tools`

### متى يجب عدم استخدام ACP

- لا يقبل سجل HTTP المهام ولا يتيح تشغيل العمليات. يستطيع المدير الداخلي
  تشغيل أداة CLI مسجّلة، لكنه غير موصول بوصفه موفّرًا احتياطيًا تلقائيًا.
  للاستخدام التفاعلي العادي، شغّل أداة CLI المهيّأة بنفسك أو
  استخدم `omniroute run`.

## أمثلة التكامل

### عرض وكلاء CLI المثبتين عبر ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### إضافة وكيل CLI مخصص

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

## متى تستخدم كل خيار

- **واجهة روبوت محادثة / مساعد برمجي** → `/v1/chat/completions` (متوافق مع OpenAI — وليس بروتوكول وكلاء)
- **التعاون بين عدة وكلاء** → A2A
- **عرض أدوات CLI المحلية في لوحة المعلومات** → ACP
- **تفويض مهام البرمجة طويلة الأمد إلى الخدمات السحابية** → الوكلاء السحابيون
