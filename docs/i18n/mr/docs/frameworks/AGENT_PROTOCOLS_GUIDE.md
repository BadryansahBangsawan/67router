67router एजंटशी संबंधित तीन वेगवेगळे पृष्ठभाग उपलब्ध करून देते. प्रथमदर्शनी ते सारखे दिसतात, परंतु ते वेगवेगळ्या समस्या सोडवतात. योग्य पर्याय निवडण्यासाठी हे पृष्ठ वापरा.

## थोडक्यात

| पृष्ठभाग                     | यासाठी सर्वोत्तम                                                                                                                      | वाहतूक माध्यम                 | मानक                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | -------------------------- |
| **A2A — एजंट-टू-एजंट**       | A2A प्रोटोकॉल वापरणाऱ्या समकक्ष एजंटसोबत आंतर-एजंट सहकार्य                                                                            | HTTP वर JSON-RPC 2.0          | A2A v0.3 (खुले विनिर्देशन) |
| **ACP — CLI एजंट रजिस्ट्री** | वापरकर्त्याच्या मशीनवर स्थापित CLI कोडिंग एजंट शोधणे / नोंदणी करणे / सुरू करणे (Cursor, Cline, Codex CLI, Claude Code, Aider इत्यादी) | HTTP REST                     | 67router-विशिष्ट           |
| **क्लाउड एजंट**              | बाह्य क्लाउड सेवांना दीर्घकाळ चालणारी कोडिंग कार्ये सादर करणे (Codex Cloud, Devin, Jules, Cursor Cloud)                               | HTTP REST + DB-समर्थित कार्ये | 67router-विशिष्ट           |

हे तिन्ही स्वतंत्र आहेत — त्यांपैकी कोणताही उपसंच निवडा.

## निर्णय-वृक्ष

## 2. ACP — CLI एजंट नोंदणी

**67router एंडपॉइंट:** `GET /api/acp/agents`
**स्रोत:** `src/lib/acp/{index,manager,registry}.ts`

### हे काय आहे

ACP ही 67router ची **स्थानिक CLI एजंट सूची** आहे. ती होस्टवर कोणते कोडिंग CLI स्थापित आहेत (Cursor, Cline, Claude Code, Codex CLI, Continue इ.) हे शोधते, त्यांच्या आवृत्त्या निश्चित करते आणि त्यांची माहिती डॅशबोर्डवर उपलब्ध करून देते, जेणेकरून वापरकर्ता प्रत्येक CLI ला 67router कडे निर्देशित करण्यासाठी जोडणी करू शकेल.

HTTP पृष्ठभाग ही एक अंतर्गत सूची आहे, जी "CLI Tools" UI आणि
CLI फिंगरप्रिंट ट्रॅकिंगला सक्षम करते ([CLI-TOOLS.md](../reference/CLI-TOOLS.md) पहा). यापासून स्वतंत्रपणे,
अंतर्गत प्रक्रिया व्यवस्थापक नोंदणीकृत Gemini लाँचरसाठी मूळ Agent Client Protocol आणि इतर करारांसाठी पारंपरिक stdio अॅडॅप्टर समर्थित करतो.
या स्वतंत्र पद्धती आणि मर्यादांसाठी [ACP नोंदणी आणि लाँचर](./ACP.md) पहा.

### हे काय करते

- स्थापित CLI बायनरींसाठी होस्टची तपासणी करते (OS नुसार `which` / `where` वापरते)
- प्रत्येक CLI ची आवृत्ती वाचते (`<bin> --version` कॉल करते)
- वापरकर्त्याने परिभाषित केलेले सानुकूल एजंट वैकल्पिकरित्या स्वीकारते (बायनरी पथ + आवृत्ती तपासणी + स्पॉन आर्ग्युमेंट्स)
- सानुकूल एजंट सेटिंग्जमध्ये कायमस्वरूपी साठवते
- एकत्रित सूची डॅशबोर्डला परत करते

### REST API

| एंडपॉइंट          | पद्धत | वर्णन                                                         | प्रमाणीकरण |
| ----------------- | ----- | ------------------------------------------------------------- | ---------- |
| `/api/acp/agents` | GET   | शोधलेले + सानुकूल एजंट सूचीबद्ध करते (स्थापित/एकूण संख्या)    | API की     |
| `/api/acp/agents` | POST  | सानुकूल एजंट जोडते/अद्ययावत करते/काढते (बॉडीमधील कृती विभेदक) | API की     |

POST साठी बॉडीची रचना (`src/app/api/acp/agents/route.ts` मधील `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### उपयोगाची प्रकरणे

- डॅशबोर्डचे "CLI Tools" पृष्ठ काय स्थापित आहे ते सूचीबद्ध करते आणि प्रत्येकाला 67router कडे निर्देशित करण्यात मदत करते
- सानुकूल एजंट प्रगत वापरकर्त्यांना 67router ला डीफॉल्टनुसार माहीत नसलेले अंतर्गत/मालकीचे CLI नोंदवू देतात
- शोध परिणाम `cli-tools` फिंगरप्रिंट मॅट्रिक्सला डेटा पुरवतो

### ACP कधी वापरू नये

- HTTP नोंदणी कार्ये स्वीकारत नाही किंवा प्रक्रिया स्पॉनिंग उपलब्ध करून देत नाही. अंतर्गत
  व्यवस्थापक नोंदणीकृत CLI लाँच करू शकतो, परंतु तो स्वयंचलित प्रदाता
  फॉलबॅक म्हणून जोडलेला नाही. सामान्य परस्परसंवादी वापरासाठी, कॉन्फिगर केलेला CLI स्वतः लाँच करा किंवा
  `omniroute run` वापरा.

## एकत्रीकरणाची उदाहरणे

### ACP द्वारे इंस्टॉल केलेल्या CLI एजंटची सूची मिळवा

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### सानुकूल CLI एजंट जोडा

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

## काय कधी वापरावे

- **चॅटबॉट / कोपायलट फ्रंटएंड** → `/v1/chat/completions` (OpenAI-सुसंगत — एजंट प्रोटोकॉल नाही)
- **मल्टी-एजंट सहयोग** → A2A
- **डॅशबोर्डमध्ये स्थानिक CLI ची सूची दाखवणे** → ACP
- **दीर्घकाळ चालणारी कोडिंग कार्ये क्लाउड सेवांना सोपवणे** → Cloud Agents
